# Aeolus media capture plan

The README, `WHY_AEOLUS.md` and `WHAT_IS_AEOLUS.md` contain commented image and GIF placeholders where each asset should appear. This file is the capture checklist.

## Capture principles

- Lead with one believable real deployment, preferably the Koonorigan property or shed system.
- Use meaningful device names and realistic data.
- Let the real site establish credibility, then use the seeded domains to show range.
- Do not turn every image into another pump and tank screenshot. The CTD profiler, escape-room console, stage cue stack, mine ventilation view and bunker power panel are useful contrasts.
- Crop browser chrome where possible and hide credentials, local IP addresses and personal details.
- Record GIFs at a readable pace. Source code should still be legible at normal GitHub width.
- Prefer PNG screenshots at 1600 x 900 or larger.
- Keep GIFs under about 20 to 25 seconds and optimise them before committing.
- Clearly label simulated data when a real device path is not available.
